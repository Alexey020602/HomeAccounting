Это приложение задумывалось как обучающее для освоения современных подходов разработки на C#.

Задача приложения - учет и анализ бюджета.
Пользователь фиксирует трату на основе данных чека или введенных вручную данных в рамках одного из бюджетов, в которых он принимает участие. 

Я собираюсь развивать проект с оглядкой на [репозиторий с эволюцией архитектуры](https://github.com/evolutionary-architecture/evolutionary-architecture-by-example).

### Модель данных

Основной сущностью является `бюджет`. Он обладает следующими свойствами:
- Название
- День месяца, с которого начинается расчетный период (например день выплаты зарплаты)
- Ограничение по расходам
- Пользователь, создавший бюджет
- Дата создания бюджета
- Пользователи, участвующие в бюджете
- Траты в рамках данного бюджета

`Трата` обладает свойствами:
- Дата покупки
- Дата добавления
- Сумма
- Описание

`Траты` могут быть двух типов `Трата на основе чека` и `Трата, добавленная вручную`. `Трата, добавленная вручную` просто хранит вручную введенные `сумму` и `описание`. `Трата на основе чека` добавляет свойства:
- Фискальные данные чека (ФД, ФН, ФП)
- Место покупки
- Пользователь, добавивший чек
- Список товаров

`Товар` содержит:
- Название 
- Стоимость
- Количество
- Сумму
