# ADR-0003: JWT + Refresh Token

## Статус

Accepted

## Контекст

Приложение — SPA на Blazor WebAssembly. Нужна аутентификация, которая:

- Работает со stateless бэкендом.
- Поддерживает автоматическое продление сессии без повторного ввода пароля.
- Допускает несколько активных сессий для одного пользователя.
- Позволяет принудительно завершить сессию (logout).

## Варианты

1. **Cookie-based sessions** — сервер хранит сессию. Простая реализация, но требует stateful backend и плохо работает с SPA на отдельном домене.
2. **JWT без refresh token** — stateless, но при коротком времени жизни токена пользователю придётся часто вводить пароль, а при длинном — повышается риск компрометации.
3. **JWT + refresh token** — короткоживущий access token + долгоживущий refresh token для обновления. Баланс между безопасностью и удобством.

## Решение

JWT access token + refresh token с ротацией:

- **Access token:** HMAC-SHA256, время жизни 1 минута (настраивается).
- **Refresh token:** 32 случайных байта (Base64), хранится в БД как SHA256-хеш, время жизни 1 день (настраивается).
- **Ротация:** при обновлении старый refresh token помечается как использованный, выдаётся новый.
- **Детекция повторного использования:** если использованный refresh token предъявляется повторно — все токены сессии удаляются (защита от кражи).
- **SessionId:** связывает цепочку refresh token'ов одной сессии.

Хранение на клиенте: `localStorage` браузера.

Подробнее: [Аутентификация](../architecture/auth.md).

## Последствия

**Положительные:**
- Stateless аутентификация: бэкенд не хранит сессии в памяти.
- Поддержка нескольких активных сессий через `SessionId`.
- Автоматическое продление без участия пользователя.
- Защита от кражи refresh token через детекцию повторного использования.
- Фоновая очистка старых токенов.

**Отрицательные:**
- `localStorage` уязвим для XSS-атак. Для повышения безопасности в будущем стоит рассмотреть httpOnly cookie.
- Сложность реализации по сравнению с cookie-based sessions.
- Невозможность мгновенного отзыва access token до истечения его срока действия (mitigated коротким временем жизни — 1 минута).
