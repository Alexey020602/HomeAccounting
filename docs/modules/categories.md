# Модуль Categories

**Пространство имён:** `HomeAccounting.Categories`
**Контекст БД:** `CategoriesContext` (схема `categories`)

## Назначение

Справочник категорий для классификации трат и товаров. Категории организованы в иерархическое дерево.

## Основные сущности

### Category

Корень агрегата.

- `CategoryId` — идентификатор
- `Name` — название категории
- `ParentCategoryId` — ссылка на родительскую категорию (null для корневых)
- `ParentCategory` — навигационное свойство
- `Children` — дочерние категории
- `Hierarchy` — объект `CategoryHierarchy`

### CategoryHierarchy

Хранит путь в дереве для эффективных запросов по предкам.

- `Path` — строковый путь вида `/1/2/3/`

## Пользовательские сценарии

### Выбор категории

1. При добавлении траты или назначении категории товару пользователь видит древовидную структуру категорий.
2. Может раскрывать/сворачивать узлы дерева.
3. Может искать категорию по названию.

### Просмотр списка категорий

1. Список категорий с фильтрацией по родительской категории.
2. Отображение иерархии и индикация наличия дочерних категорий.

## API endpoints

Все endpoints доступны без авторизации (справочные данные).

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/categories` | Список категорий (опционально `ParentId`) |
| `GET` | `/api/categories/tree` | Полное дерево категорий |
| `GET` | `/api/categories/csv` | Экспорт категорий в CSV |

## Ограничения и правила

- Категории образуют дерево через `ParentCategoryId`.
- `CategoryHierarchy` (path-based) используется для запросов по предкам/потомкам.
- Изменения категорий — в границах агрегата `Category`.

## Зависимости от других модулей

- Модуль Categories не зависит от других доменных модулей.
- Модуль Budgets ссылается на `CategoryId` для привязки категорий к операциям и товарам.
